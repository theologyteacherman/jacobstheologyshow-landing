# jacobstheologyshow-landing

This repo serves the landing page (homepage) for [www.jacobstheologyshow.com](https://www.jacobstheologyshow.com) via GitHub Pages.

It contains a single `index.html` with all CSS inlined so the page loads fast and has no external dependencies on other repos.

The rest of the site (Listen, Episodes, Tools, Games, Music, Contact) lives in the [fullgamesite3](https://github.com/theologyteacherman/fullgamesite3) repo and is linked to from the nav bar using absolute URLs.
